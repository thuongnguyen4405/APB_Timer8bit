## Specific pitfall visible in the original source

A screenshot shows `8'h100` and QuestaSim's **redundant digits in numeric literal** warning. An eight-bit hex literal `8'h100` truncates to zero; to represent *decimal* 100, use `8'd100` or `8'h64`. The re-created project uses the corrected value. The historical screenshot should therefore not be treated as a fresh run validating the corrected intended data bin.
